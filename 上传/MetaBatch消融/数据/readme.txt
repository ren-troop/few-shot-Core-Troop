Accompanying code for our paper: https://github.com/haozhen315/CCAM-China-Basin-Attributes-and-Meteorology-dataset

It supports generating 120+ basin attributes for each basin given a single or several basin boundaries. Except for the netCDF and Meteorological time series data, which only covers China, other data sources are global, which means that the code can also be used to calculate these attributes of basins in other regions.

######################################################################

Description

This is the dataset supporting the paper: CCAM: China Catchment Attributes and Meteorology dataset.

It consists of two parts: CCAM: China Catchment Attributes and Meteorology dataset and HydroMLYR. 

The first dataset provides daily meteorological time series and 120+ attributes for 4911 catchments in China.

The daily meteorological time series include (i) precipitation, (ii) temperature, (iii) evapotranspiration, (iv) wind speed, (v) ground surface temperature, (vi) pressure, (vii) humidity, (viii) sunshine duration and (ix) potential evapotranspiration.

The catchment attributes include properties such as (i) topography, (ii) climate, (iii) hydrology, (iv) land cover, (v) geology, and (vi) soil.

The dataset follows similar standards from the CAMELS datasets: United States (https://doi.org/10.5194/hess-21-5293-2017), Chile (https://doi.org/10.5194/hess-22-5817-2018), Great Britain (https://doi.org/10.5194/essd-2020-49) and Brazil (https://doi.org/10.5194/essd-12-2075-2020).

Please refer to HydroMLYR's separate readme file for details.
