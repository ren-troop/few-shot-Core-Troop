# 黄河流域完整对比补充实验报告

## 1. 补充内容

本次补充完成了以下四项：

- 300-step 训练。
- 多 seed 重复实验。
- `FO-MAML`、`二阶 MAML`、`Meta-SGD` 完整对比。
- 有无半监督完整对比。

实验固定采用前期推荐的跨区域主配置：

```text
inner_steps = 3
meta_batch = 8
shots = 8
queries = 16
unlabeled_per_task = 16
```

这样做的目的不是再扩大所有超参数网格，而是在已经确定较优配置后，验证算法选择和半监督机制在黄河真实数据上的稳定性。

## 2. 数据来源

数据使用黄河流域真实水文数据 HydroMLYR：

- 数据集：HydroMLYR，属于 CCAM: China Catchment Attributes and Meteorology dataset。
- DOI：https://doi.org/10.5281/zenodo.5729444
- 本地模型输入文件：`yellow_river_data/yellow_river_hydromlyr_model_ready.csv`

框架读取后的数据规模：

| 项目 | 数值 |
|---|---:|
| 有效样本数 | 26079 |
| 输入特征数 | 16 |
| 预测目标 | 标准化径流 q |
| 数据划分方式 | 按流域构造跨区域任务 |

每个 seed 会重新划分训练流域和验证流域，用于检验结论是否依赖某一次随机划分。

## 7. 结果分析

### 7.1 哪个算法最适合当前任务

从平均 RMSE 看，排序为：

1. `FO-MAML + 无半监督`：0.633026
2. `FO-MAML + 有半监督`：0.633222
3. `二阶 MAML + 无半监督`：0.635724
4. `二阶 MAML + 有半监督`：0.637298
5. `Meta-SGD + 无半监督`：0.637544
6. `Meta-SGD + 有半监督`：0.638005

因此，当前最适合作为主方案的是：

```text
FO-MAML + 无半监督 + inner_steps=3 + meta_batch=8
```

它同时具备最低平均 RMSE 和最低平均训练时间。

### 7.2 半监督是否带来稳定收益

从结果看，半监督没有带来稳定提升：

- FO-MAML：半监督平均 RMSE 从 `0.633026` 变为 `0.633222`，略差。
- 二阶 MAML：半监督平均 RMSE 从 `0.635724` 变为 `0.637298`，略差。
- Meta-SGD：半监督平均 RMSE 从 `0.637544` 变为 `0.638005`，略差。

同时，半监督显著增加训练时间：

- FO-MAML：从 `0.028966 s/step` 增加到 `0.045103 s/step`。
- 二阶 MAML：从 `0.049877 s/step` 增加到 `0.083468 s/step`。
- Meta-SGD：从 `0.051475 s/step` 增加到 `0.086014 s/step`。

因此，当前半监督伪标签机制可以证明“框架能接入无标签数据”，但还不能证明“效果稳定优于纯监督”。

### 7.3 二阶 MAML 是否优于 FO-MAML

二阶 MAML 理论上保留了更完整的梯度信息，但在本实验中没有优于 FO-MAML：

- 平均 RMSE 高于 FO-MAML。
- 平均 MAE 与 FO-MAML 接近。
- 平均每步时间明显高于 FO-MAML。

因此，在当前黄河流域跨区域任务中，二阶 MAML 更适合作为对照组，而不是主方案。

### 7.4 Meta-SGD 的表现如何

Meta-SGD 的平均 MAE 最低，但平均 RMSE 高于 FO-MAML。这个现象说明：

- Meta-SGD 对大部分样本的绝对误差可能较小。
- 但它可能在部分样本或部分流域上出现较大的误差，使 RMSE 被拉高。
- 这与 Meta-SGD 学习每个参数 inner learning rate 的机制有关，表达能力更强，但也更容易受任务差异和学习率约束影响。

因此，Meta-SGD 可以保留为后续改进方向，但当前不建议作为主方案。

## 8. 对项目技术路线的影响

本次补充实验支持以下技术路线：

第一阶段主线：

```text
FO-MAML + 无半监督 + inner_steps=3 + meta_batch=8
```

目标是形成稳定可靠的跨区域预测基线。

第二阶段半监督增强：

```text
FO-MAML + 半监督 + inner_steps=3 + meta_batch=8
```

但需要改进伪标签机制，例如加入置信度阈值、动态 `ssl_weight`、水文物理约束或一致性正则。

第三阶段算法探索：

```text
Meta-SGD 或二阶 MAML
```

用于补充对照和方法创新，但需要更多调参和稳定性验证。

## 9. 最终结论

完成 300-step、多 seed、三算法、有无半监督完整对比后，当前最稳妥的结论是：

> 在黄河流域跨区域水文预测任务中，`FO-MAML + 无半监督 + inner_steps=3 + meta_batch=8` 是当前最适合作为主实验路线的配置。它在多 seed 平均结果中取得最低 RMSE，同时训练速度最快。半监督机制目前尚未带来稳定收益，应作为后续增强模块继续优化，而不是直接作为默认主方案。
