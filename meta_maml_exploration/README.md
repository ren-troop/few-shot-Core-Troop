# MAML 学习率与正则化元学习探索实验

## 项目简介

本项目使用公开的 Omniglot 手写字符数据集，在统一的 5-way 1-shot 少样本分类条件下，对 MAML 进行两方面拓展实验：

1. 学习率元学习：使用 Meta-SGD 学习模型参数的更新尺度和方向。
2. 正则化元学习：使用 Meta-L2 学习不同权重层的 L2 正则化系数。

为了公平判断拓展方法是否有效，项目同时设置普通 MAML 和固定 L2 两个对照组。四种方法使用相同的数据、网络结构、任务采样方式和训练参数。

本项目主要回答两个问题：

- 内循环学习率由模型自动学习，是否比人工固定学习率更有利于新任务适应？
- 不同网络层的正则化强度由模型自动学习，是否比使用固定 L2 更能抑制少样本过拟合？

## MAML 基线

MAML 全称为 Model-Agnostic Meta-Learning，即模型无关元学习。它的目标不是只学习一个固定分类任务，而是学习一组适合快速适应新任务的初始参数。

每个少样本任务被划分为两部分：

- Support Set：用于当前任务的快速学习；
- Query Set：用于评价快速学习后的泛化表现。

MAML 包含两个循环：

1. 内循环：模型使用 Support Set 进行一次或少数几次梯度更新，得到当前任务的适应参数。
2. 外循环：模型使用适应后的参数预测 Query Set，再根据 Query Set 损失改进共同的初始参数。

普通 MAML 的一次内循环更新可表示为：

```text
适应后参数 = 初始参数 - 固定学习率 × Support Set 梯度
```

本项目把 MAML 作为共同基线，分别研究学习率和正则化是否也可以参与元学习。

## 模型一 Meta-SGD 学习率元学习

普通 MAML 通常给所有参数使用同一个固定内循环学习率。但是，不同网络参数承担的功能不同：底层卷积参数可能需要保持稳定，分类层参数可能需要更快适应新类别。

Meta-SGD 在学习 MAML 初始参数的同时，还为每个参数学习对应的更新系数：

```text
适应后参数 = 初始参数 - 可学习更新系数 × Support Set 梯度
```

与普通 MAML 相比，Meta-SGD 额外学习：

- 每个参数应该更新多大；
- 不同参数是否需要不同更新速度；
- 某些参数是否适合沿与普通梯度相反的方向更新。

因此，本项目用下面的比较研究学习率元学习：

```text
MAML 固定学习率  对比  Meta-SGD 可学习参数级学习率
```

## 模型二 Meta-L2 正则化元学习

1-shot 任务中，每个类别只有一张 Support Set 图片，模型容易记住个别图片的偶然细节，导致 Support Set 表现很好，但 Query Set 表现较差，这种现象称为过拟合。

L2 正则化通过惩罚过大的权重，限制模型对少量支持样本反应过度。普通 L2 使用人工设定且训练过程中固定不变的系数。

本项目首先设置 `fixed_l2` 对照组，在 MAML 内循环的 Support Set 损失中加入固定 L2。随后设置 `meta_l2`，让外循环根据 Query Set 表现学习不同权重层的非负 L2 系数。

正则化实验包含两层比较：

```text
MAML  对比  Fixed-L2：判断加入普通 L2 是否有效
Fixed-L2  对比  Meta-L2：判断学习 L2 强度是否优于固定 L2
```

`meta_l2` 是用于本次探索实验的可解释变体，不是对某篇 MetaReg 论文的完整复现。

## 四种实验方法

| 方法 | 初始参数 | 内循环学习率 | L2 正则化 | 实验作用 |
| --- | --- | --- | --- | --- |
| `maml` | 元学习 | 人工固定 | 无 | 共同基线 |
| `meta_sgd` | 元学习 | 逐参数元学习 | 无 | 学习率元学习实验 |
| `fixed_l2` | 元学习 | 人工固定 | 人工固定 | 普通正则化对照 |
| `meta_l2` | 元学习 | 人工固定 | 按权重层元学习 | 正则化元学习实验 |

## Omniglot 数据集

Omniglot 是面向少样本学习的公开手写字符数据集，包含来自不同文字系统的大量字符类别，每个字符由多位书写者分别书写。

本项目使用 Torchvision 提供的 Omniglot 接口：

- `background=True`：用于元训练；
- `background=False`：用于最终测试；
- 图片统一缩放为 28×28 灰度图；
- 训练类别与测试类别分离，用于检验模型能否适应训练阶段没有见过的字符类别。

每个 Episode 随机生成一个 5-way 1-shot Task：

| 组成 | 数量 | 用途 |
| --- | ---: | --- |
| 字符类别 | 5 类 | 构成一个少样本任务 |
| Support Set | 每类 1 张，共 5 张 | 当前任务内循环适应 |
| Query Set | 每类 5 张，共 25 张 | 评价适应后的泛化能力 |

5-way 分类的随机猜测准确率约为 20%。模型需要在保留测试字符类别上明显高于随机水平，才说明学到了可迁移的快速适应能力。

## 实验假设

### H1 学习率元学习假设

Meta-SGD 能够针对不同参数学习不同的更新尺度和方向，因此在相同的一步适应条件下，可能比固定学习率 MAML 获得更高的测试准确率、更低的测试损失，或者用更少 Episode 达到相近准确率。

主要比较：

```text
maml 与 meta_sgd
```

### H2 正则化元学习假设

不同网络层对快速适应和特征稳定性的要求不同。Meta-L2 通过外循环学习各权重层的 L2 系数，可能比固定 L2 更好地抑制 1-shot 适应过程中的过拟合，使 Query Set 准确率更高或跨任务波动更小。

主要比较：

```text
fixed_l2 与 meta_l2
```

MAML 与 Fixed-L2 的比较用于判断普通 L2 本身是否产生效果。

### H3 保守假设

Meta-SGD 和 Meta-L2 增加了需要学习的元参数。如果训练 Episode 不足、任务较简单或超参数不合适，拓展方法不一定立即优于基线。

当方法差异很小、95% 置信区间大量重叠或不同随机种子的趋势不一致时，应记录为“当前证据不足”，而不是直接声称方法一定有效或完全无效。

## 实验设置

| 项目 | 设置 |
| --- | --- |
| 数据集 | Omniglot |
| 任务形式 | 5-way 1-shot |
| Query 数量 | 每类 5 张 |
| 网络 | 4 个卷积块加线性分类层 |
| 内循环步数 | 1 |
| 正式训练 Episode | 每种方法 600 |
| Meta Batch | 4 个 Task |
| 测试 Task | 每种方法 200 |
| 随机种子 | 42，建议补充 43 和 44 |

除实验方法外，其余设置必须保持一致，才能进行公平比较。
