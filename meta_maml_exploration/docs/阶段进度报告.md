# MAML 学习率与正则化元学习探索实验阶段进度报告

## 一 与项目计划书的关系

项目计划书要求建立模块化的 PyTorch 实验框架，并沿“合成数据、公开数据集、实际数据”逐步验证 MAML、Meta-SGD 等小样本学习方法。本次工作属于公开数据集阶段的视野拓展实验，目的不是直接解决黄河流域时间序列预测问题，而是先用结构清楚的少样本分类任务理解两类可迁移机制：内循环更新规则能否由元学习得到，以及内循环正则化强度能否由元学习得到。

为避免实验范围过大，本阶段只改变一个因素，其余条件保持一致。后续若结论清楚，可将同样的接口迁移到正弦波回归或项目中的生态时间序列任务。

## 二 已完成工作

1. 选用公开 Omniglot 手写字符数据集，按官方 background 集训练、evaluation 集测试。
2. 建立 5-way 1-shot episodic 任务，每个任务分为 support set 和 query set。
3. 实现固定内循环学习率的 MAML 基线。
4. 实现 Meta-SGD 风格的学习率元学习：每个模型参数都有可学习的更新步长，步长及方向由外循环优化。
5. 实现固定 L2 对照组，用于区分“加入正则化”与“学习正则化强度”的效果。
6. 实现 Meta-L2 正则化元学习：每个权重层拥有非负、可学习的 L2 系数，系数通过查询集表现反向更新。
7. 实现统一训练、测试、日志保存、置信区间计算和结果绘图流程。

## 三 实验假设

### H1 学习率元学习假设

在相同的一步适应条件下，Meta-SGD 比固定学习率 MAML 更能针对不同参数选择合适的更新尺度和方向，因此测试任务准确率可能更高，或收敛速度更快。

### H2 正则化元学习假设

1-shot 支持集很小，模型容易在内循环中过拟合。由外循环学习各层 L2 系数，可以让需要稳定的层受到更强约束，让需要快速适应的层保持较弱约束，因此查询集准确率可能提高，跨任务波动可能减小。

### H3 保守假设

如果训练 episode 太少、任务本身较简单或元参数尚未收敛，两种拓展方法可能没有明显优于基线。若 95% 置信区间明显重叠，只能写“当前证据不足”，不能写“显著提升”。

## 四 对照实验设置

| 项目 | 设置 |
| --- | --- |
| 数据集 | Omniglot |
| 训练和测试划分 | background 训练，evaluation 测试 |
| 任务形式 | 5-way 1-shot |
| 查询样本 | 每类 5 张 |
| 网络 | 4 个卷积块加线性分类头 |
| 内循环步数 | 1 |
| 外循环优化器 | Adam |
| 基线 | 固定学习率 MAML |
| 实验一 | Meta-SGD 风格逐参数学习率 |
| 正则化对照 | 固定 L2 |
| 实验二 | Meta-L2 逐层可学习正则化 |
| 主要指标 | 查询集准确率、损失、标准差和 95% 置信区间 |

四组方法必须使用相同的数据划分、任务设置、网络规模、训练 episode 数、meta batch 和随机种子。否则结果不能直接比较。

## 七 汇报时可以这样说明

本阶段没有直接改动项目的时间序列主任务，而是先在标准公开少样本数据集上做机制验证。四组实验共用同一 MAML 框架。第一组把固定学习率作为基线；第二组让模型学习每个参数应该迈多大一步；第三组加入固定 L2；第四组让模型学习不同层应受到多强的 L2 约束。固定 L2 组可以排除“结果变化只是因为加入正则项”这一混淆因素。最终不仅比较准确率，也保存学到的步长和正则化系数，用来解释模型学到了什么。
