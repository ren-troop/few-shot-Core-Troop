# 本轮运行图表说明

正式运行 `run_windows.bat` 后，`--plots` 会在每个 `outputs_review_seed*/` 目录生成：

| 文件 | 内容 |
| --- | --- |
| `comparison.png` | 各方法验证曲线和最终测试准确率 |
| `l2_trajectory.png` | Meta-L2 各层正则系数轨迹 |
| `learning_rate_signs.png` | Meta-SGD clamp 后各层有效步长的符号分布 |

clamp 模式下不应出现负的有效学习率。图表只反映对应 seed，正式结论应以跨 seed CSV 汇总为准。PNG 保留在本机输出目录，不提交 Git。
