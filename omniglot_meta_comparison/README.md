# Omniglot 元学习：代码修改、本次结果与上次对比

本文件只记录三件事：

1. 这次代码相对上一版改了什么；
2. 这次 Omniglot 训练结果如何；
3. 与上一次 Omniglot 结果相比，差异从哪里来。

## 0. 结论

本次 seed 42、5-way 1-shot、600 个 meta episode、200 个测试任务：

| 方法 | 测试准确率 | 95% CI | 测试 loss |
|---|---:|---:|---:|
| MAML | **76.70%** | ±1.81 | 0.620 |
| Meta-SGD | **75.22%** | ±1.88 | 0.649 |
| Meta-L2 | **76.44%** | ±1.81 | 0.627 |
| Fixed-2 | **38.60%** | ±1.84 | 406.59* |

\* Fixed-2 的 loss 不是正常可比的交叉熵量级，原因见第 5.4 节；只应比较它的准确率。

与上一次 seed 42 相比：

| 方法 | 上次 seed 42 | 本次 seed 42 | 变化 |
|---|---:|---:|---:|
| MAML | 61.90% | 76.70% | **+14.80** |
| Meta-SGD | 53.76% | 75.22% | **+21.46** |
| Meta-L2 | 61.24% | 76.44% | **+15.20** |
| fixed_l2 → Fixed-2 | 59.16% | 38.60% | 不是同一方法，不能直接比较 |

三个元学习方法都明显高于上一版；Fixed-2 是这次新换的基线，不能拿旧 `fixed_l2` 当作同一个方法。

## 2. 本次代码逻辑做了哪些修改

### 2.1 用 Fixed-2 替换 fixed_l2

上一版第四个方法是 `fixed_l2`：

```text
MAML + 固定 L2 正则
```

它仍然做 episodic 元训练，只是内循环 loss 加一个固定的权重 L2。

这次换成 Fixed-2：

1. 先在 771 个训练字符上做普通多分类预训练；
2. 预训练 30 个 epoch；
3. 冻结 Conv4 骨干；
4. 每个 episode 新建 5 路线性头；
5. 只用 5 张 support 对线性头做 2 步 SGD，学习率 0.05；
6. 在 25 张 query 上评估。

这带来的是**方法定义的变化**，不是同一方法的参数调整。  
因此 `fixed_l2=59.16%` 和 `Fixed-2=38.60%` 不能直接说成“变差了 20 个点”。

### 2.2 Meta-L2 从逐层权重 L2 改成标量锚正则

上一版 Meta-L2：

```text
CE + Σ_layer λ_layer · mean(weight²)
```

每个权重层一个可学习 `λ`，正则的是权重本身。

这一版 Meta-L2：

```text
CE + (λ/2) · Σ_i (θ'_i − θ_i)²
```

只有一个标量 `λ`，锚定每个 episode 的初始参数 `θ`。

但这次 Omniglot 的 **内循环只有 1 步**，这个改动导致一个关键问题：

- 初始时 `θ' = θ`，所以 `(θ'−θ)²` 的梯度为 0；
- 第 1 步更新后的 `θ'` 与 `λ` 无关；
- query loss 对 `λ` 的梯度为 0；
- 训练日志里 600 个 episode 的 `λ` 全部是 `0.0010000000474974513`。

所以**这次 Meta-L2 实际上就是 MAML**，它没有学到任何正则强度。

### 2.3 Meta-SGD 去掉了 0.2 的步长上限

上一版 Meta-SGD 使用：

```text
clamp(raw_lr, 1e-6, 0.2)
```

而 MAML 的固定步长是 0.4。  
也就是说旧 Meta-SGD 一开始就被限制在 0.2，内循环步长只有 MAML 的一半。

这一版改成：

```text
softplus(raw_lr)，上限 1.0
```

本次学到的平均内循环步长是 **0.384**，接近 MAML 的 0.4。

### 2.4 模型初始化变了

上一版 `OmniglotConvNet` 使用 PyTorch 默认初始化：

- Conv 默认 Kaiming uniform；
- Linear 默认 uniform，范围约 `±1/sqrt(32) ≈ ±0.177`。

这一版显式初始化：

- Conv 使用 Kaiming normal；
- Linear 使用 `std=0.01`；
- bias 置零。

在 1-shot、1 步内循环的设置下，分类头初始 logit 太大容易让 support 梯度不稳定。  
把线性层初始化缩小到 0.01，是本版 MAML/Meta-SGD/Meta-L2 提升的最可能原因之一。

### 2.5 代码结构清理

删除了：

- `fixed_l2` 方法；
- `src/common/meta_sgd_lr.py` 及 clamp/softplus/none 三种模式；
- 逐层 L2 trajectory 和大量诊断字段；
- `results/`、`tools/`、`tests/`、水质数据、旧 README、PR 文档。

保留：

- `meta_experiment/`：数据、模型、四种 learner、配置、工具；
- `train.py`：单方法训练；
- `run_all.py`：四种方法顺序训练；
- `plot_results.py`：验证曲线、测试柱状图、超参数曲线。

## 5. 原因分析

### 5.1 为什么 MAML 从 61.90% 提升到 76.70%

MAML 的算法本身没变，主要变化是模型初始化：

- 旧版 Linear 默认初始化范围约 ±0.177；
- 新版 Linear 初始化 std=0.01；
- Conv 从默认初始化改成显式 Kaiming normal。

在 1-shot、1 步内循环下，初始分类头 logit 太大，会让 support 集梯度方向更 noisy。  
缩小分类头初始化后，MAML 的 600 个 episode 训练曲线从 50.64% 稳定升到 77.20%。

同时，旧版 MAML 的 3-seed 标准差是 2.73，本次 +14.80 远大于这个波动，说明提升不太可能只是 seed 碰巧。

### 5.2 为什么 Meta-SGD 从 53.76% 提升到 75.22%

这是四个变化里原因最明确的：

```text
旧版：clamp(raw_lr, 1e-6, 0.2)
新版：softplus(raw_lr)，上限 1.0
```

旧版 Meta-SGD 的内循环步长最大只有 0.2，而 MAML 固定用 0.4。  
也就是说旧版 Meta-SGD 从第一步起就比 MAML 学得慢，测试准确率只有 53.76% 是合理的。

新版平均步长 0.384，接近 MAML 的 0.4，所以准确率恢复到 75.22%。  
但它仍然略低于 MAML（-1.48），说明“逐参数学习率”在 Omniglot 1-shot、600 episode 的设置下没有带来额外收益。

### 5.3 为什么 Meta-L2 看起来提升了，但并没有真的学会正则

Meta-L2 从 61.24% 到 76.44%，表面上 +15.20，但这不是 L2 的功劳。

原因是 1 步内循环：

```text
θ' = θ − α∇(CE + (λ/2)||θ−θ||²)
```

在初始点 `θ` 处，`||θ−θ||²` 的梯度是 0，所以第一步更新与 `λ` 无关。  
query loss 对 `λ` 的梯度也是 0，训练日志中 600 个 `λ` 全部保持 0.001。

因此本次 Meta-L2 等价于 MAML，76.44% 只是 MAML 的另一个数值路径。  
它和 MAML 的 0.26 个百分点差异在 ±1.81 的测试 CI 内，没有意义。

### 5.4 为什么 Fixed-2 只有 38.60%，loss 还是 406

Fixed-2 的预训练训练准确率有 90.60%，说明表征不是完全没学到。  
但测试只有 38.60%，原因在于适配预算：

- 5-way 1-shot 只有 5 张 support；
- 只训练线性头 2 步；
- 学习率 0.05；
- 没有特征归一化。

这会让新分类头在 2 步内严重欠拟合，support/query 的 logit 尺度也可能变得很大。  
测试 loss 406 不是正常的 5-way 交叉熵量级，不能和 MAML 的 0.62 直接比较；**Fixed-2 只看准确率**。

另外，旧的 `fixed_l2=59.16%` 是“MAML + 固定 L2”的元训练结果，不是“冻结骨干 + 线性头”的结果。  
把 Fixed-2 和 fixed_l2 放在同一列比较，会错误地得出“固定表征退化了 20 个点”的结论。

### 5.5 为什么本次三个元学习方法都高于上次

按影响从大到小：

1. **初始化改变**：线性头 std 从约 0.177 降到 0.01，1 步 MAML 更稳定；
2. **Meta-SGD 上限改变**：从 0.2 放到 1.0，实际步长从 0.2 恢复到 0.384；
3. **Meta-L2 实现改变**：从逐层权重 L2 变成标量锚 L2；但 1 步下没有生效，所以它只是跟随 MAML 提升；
4. **单 seed vs 3 seed**：本次只有一个 seed，不能排除 seed 波动，但 +14.8 远大于旧版 2.73 的标准差；
5. **GPU vs CPU**：只影响速度，不应造成 15 个点的准确率差异。

### 5.6 训练是否收敛

没有完全收敛。

三个方法的验证曲线到 600 episode 仍在上升：

```text
MAML     50.64 → 60.24 → 68.64 → 71.20 → 74.64 → 77.20
Meta-SGD 49.92 → 57.52 → 68.00 → 71.04 → 72.96 → 76.48
Meta-L2  50.32 → 62.56 → 68.72 → 73.12 → 74.64 → 78.08
```

所以当前 76% 左右不是这些方法的 Omniglot 上限，继续训练到 1,000–2,000 episode 可能还会提升。  
这也意味着现在的排序（MAML vs Meta-SGD vs Meta-L2）还不稳定。

## 6. 局限与下一步

1. **只有一个训练 seed**：本次 76.70/75.22/76.44 不能当作最终均值；至少补 seed 43/44。
2. **600 episode 偏少**：验证曲线仍在上升，建议 1,500–2,000 episode。
3. **Meta-L2 在 1 步内循环下无效**：要验证 Meta-L2，至少用 2–5 步内循环，或改回固定/逐层权重 L2。
4. **Fixed-2 需要消融**：建议补 10 步/50 步线性头，或者做特征归一化、降低 `fixed2-lr`；当前 2 步不足以代表固定表征的上限。
5. **Fixed-2 的 loss 不可比**：如果论文要报告 loss，需要先处理 logit 尺度过大的问题。
6. **没有 5-shot**：当前是 1-shot；5-shot 下 Fixed-2 和 Meta-SGD 的结论可能不同。
